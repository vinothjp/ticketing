

Recommended Full Stack
Layer				Technology					Reason
Backend				Node.js + Express / NestJS	JSON REST or GraphQL API works identically for web and mobile
Database			PostgreSQL					Robust, relational, scales well
ORM					Prisma						Type-safe, easy migrations
Auth				JWT + Refresh Tokens		Works on web browsers AND mobile apps natively
Web Frontend		React + TypeScript			Component-based, large ecosystem
Mobile App			React Native				Same language as web (TypeScript), share business logic
Shared Code			Monorepo (Turborepo / Nx)	Share types, API clients, and hooks between web and mobile
API Docs			Swagger / OpenAPI			Other apps can integrate easily
File/Image Storage	AWS S3 / Cloudflare R2		Works for both web and mobile uploads
Push Notifications	Firebase FCM				Required for mobile, easy to add later

rbac-app/
├── apps/

├── packages/
│   ├── types/        ← Shared TypeScript interfaces (User, Role, Permission)
